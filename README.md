## 🌊 Overview & Scientific Methodology

This system integrates spaceborne radar remote sensing, physical oceanography, and maritime trajectory analytics to assist authorities in detecting marine slicks and identifying potential vessel candidates without asserting definitive legal guilt.

```
+---------------------+     +--------------------+     +------------------------+
| Sentinel-1 C-SAR    | --> | PyTorch U-Net      | --> | WGS84 Geodesic         |
| GRD Level-1 (VV)    |     | Segmentation (Dice)|     | Polygon Characterize   |
+---------------------+     +--------------------+     +------------------------+
                                                                   |
                                                                   v
+---------------------+     +--------------------+     +------------------------+
| Explainable AIS     | <-- | MarineCadastre AIS | <-- | Lagrangian 2D          |
| Candidate Ranking   |     | Trajectory Filter  |     | Particle Backtracking  |
+---------------------+     +--------------------+     +------------------------+
```

### 1. SAR Segmentation (PyTorch U-Net)
- **Physics**: Capillary and short gravity wave damping reduces radar backscatter intensity.
- **Architecture**: 4-level U-Net with skip connections, trained on Dice + BCE composite loss.
- **Look-alikes**: NOT filtered. Only a low-wind flag (< 3 m/s at the observation time) raises the look-alike hypothesis H2; there is no look-alike classifier (it is blocked by missing labelled data, see `ml/extensions/capabilities.json`).

### 2. GIS Geodesic Surface Characterization
- Computes spherical polygon excess area in $\text{km}^2$ and hectares, perimeter, WGS84 centroid, and orientation angle.

### 3. Lagrangian Particle Drift Backtracking
- 2D advection-diffusion Monte Carlo simulation utilizing Copernicus Marine surface currents ($\mathbf{u}_{\text{curr}}, \mathbf{v}_{\text{curr}}$) and ECMWF ERA5 10m leeway winds ($\mathbf{u}_{10}, \mathbf{v}_{10}$ with 3% factor and Coriolis deflection).
- Estimates probable discharge origin centroid and 90% confidence uncertainty radius ($R_{90\%}$).

### 4. AIS Trajectory Reconstruction & Multi-Factor Scoring
- Filters vessel transmissions temporally and spatially.
- Evaluates composite attribution score:
  $$S_{\text{composite}} = w_{\text{spatial}} S_{\text{spatial}} + w_{\text{temporal}} S_{\text{temporal}} + w_{\text{trajectory}} S_{\text{trajectory}} + w_{\text{consistency}} S_{\text{consistency}}$$

## 🚀 Quickstart for Students

### 1. Clone & Install Dependencies
```bash
# Clone the repository
cd oil-spill-attribution

# Python backend dependencies
pip install -r requirements.txt

# Node & UI dependencies
npm install
```

### 2. Run Automated Verification Tests
```bash
python3 -m unittest tests/test_pipeline.py
```
*(All 8 unit and integration tests will execute and verify the end-to-end pipeline).*

### 3. Launch Application
```bash
npm run dev
```
Open **http://localhost:3000** in your browser to interact with the GIS Dashboard.

## 📡 Data sources (the web server analyses stored data; live ingestion is NOT implemented in the server)

| Dataset | Provider | Python Client / API | Configuration |
| :--- | :--- | :--- | :--- |
| **Sentinel-1 SAR GRD** | Copernicus Data Space | `requests` / OData API | `CDSE_CLIENT_ID`, `CDSE_CLIENT_SECRET` in `.env` |
| **Ocean Currents** | Copernicus Marine (CMEMS) | `copernicusmarine` SDK | `CMEMS_USERNAME`, `CMEMS_PASSWORD` |
| **10m Winds** | ECMWF CDS (ERA5) | `cdsapi` client | `~/.cdsapirc` or `CDSAPI_KEY` |
| **Vessel AIS** | MarineCadastre.gov / AISHub | GeoJSON / CSV stream | Stored in `./data/ais/` |

## ⚖️ Scientific & Legal Disclaimer

**DECISION-SUPPORT SYSTEM ONLY:** All candidate rankings generated by this application reflect mathematical spatio-temporal correlations between observed slicks, hydrodynamic drift models, and AIS trajectory logs. 

Attribution scores represent probabilistic evidence alignment for investigative triage and **do not constitute definitive proof or legal accusation of environmental discharge violation**. In-situ water sampling, aerial surveillance, and port state control inspections remain required for legal enforcement.
